# Rishe Store

فروشگاه مستقل ریشه، بازطراحی‌شده از صفر بر اساس محتوای فعلی برند و دو سند IA و SEO V3.

## معماری

- Next.js App Router
- PostgreSQL + Prisma
- احراز هویت اختصاصی با Cookie امن
- فروشگاه، دسته‌بندی، محصول، پک، سبد خرید و Checkout
- حساب کاربری و تاریخچه سفارش
- پنل مدیریت محصولات، سفارش‌ها، محتوا، تصاویر و تنظیمات
- پرداخت NextPay با Verify سمت سرور
- FAQ، مجله، Sitemap، Robots و Structured Data
- Docker Compose + PostgreSQL + Caddy HTTPS
- دیپلوی خودکار با GitHub Actions روی new.rishe.store

## اولین راه‌اندازی

بعد از اولین Deploy، به این آدرس برو:

https://new.rishe.store/setup

اولین مدیر، هزینه ارسال و در صورت آماده بودن کلید API نکست‌پی را ثبت کن. بعد از ساخت مدیر، صفحه Setup بسته می‌شود.

محصولات فعلی شناخته‌شده از اسناد پروژه به‌صورت کاتالوگ پایه Seed شده‌اند، اما قیمت و موجودی عمداً صفر هستند تا قیمت ساختگی وارد سایت نشود. در پنل /admin قیمت، موجودی، وزن، عکس و اطلاعات هر محصول را تکمیل و تأیید کن.

## Secrets لازم برای Deploy

در GitHub Actions:

- HOST — IP/Host سرور
- PASS — رمز SSH
- SSH_USER — اختیاری؛ اگر خالی باشد root استفاده می‌شود

DNS دامنه new.rishe.store باید مستقیماً به سرور اشاره کند. Caddy روی سرور SSL را خودکار می‌گیرد.

## پرداخت

اتصال نکست‌پی بر اساس REST API رسمی پیاده شده است. کلید API در دیتابیس با APP_SECRET رمزنگاری می‌شود. مبلغ سفارش از دیتابیس سمت سرور محاسبه و Callback نیز مبلغ، Order ID و Transaction ID را دوباره تطبیق می‌دهد.
